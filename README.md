# The repository for assessing transition risks of coal-fired power plants (transition-risk-cffp)
This repository contains the data and code for assessing the transition risks of coal-fired power plants, as presented in Ju et al. (2025, under review). The stranded assets of coal power plants under different long-term decarbonization transition pathways are assessed by utilizing an Integrated Assessment Model (MESSAGEix model), focusing on regions highly dependent on coal, i.e., China, South Asia, other Pacific Asia, and the rest Centrally Planned Asia.

## What is contains
- ✅ Application workflow based on MESSAGEix model
- ✅ New technologies: ammonia-cofiring, biomass-cofiring, retrofitted CCS in coal power plants
- ✅ Scenario building and solving
- ✅ Scenario reporting
- ✅ Result plotting

## Installation
If `message_ix`, `ixmp`, `message_ix_models` are installed in the environment,

```bash
git clone https://github.com/yiyi1991/transition-risk-cffp.git
cd transition-risk-cffp
pip install -e .
```
If not,
```bash
pip install -r requirements.txt
```
